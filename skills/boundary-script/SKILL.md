# 边界与拒绝话术

## 什么时候用
- 有人反复求助但零回馈
- 对方享受你推进却不给确定答复（悬置）
- 需要说「不」但怕关系破裂

## 步骤
1. **先算账，不谈感受**：付出次数/权重 vs 得到次数/权重。用系统里的互动流水，别凭印象。
2. **判断结构**：对等 / 我方净输出 / 对方净输出 / 不清晰。不清晰就说证据不足。
3. **区分两件事**：他要的是你的能力（可定价），还是你的不好意思（可收割）。
4. **给红线**：写成 if-then，例如「如果再出现第三次无回报的加急请求，我直接说档期满了」。
5. **给原话**：一句话，不带指责、不留解释空间、也不讨好。

## 输出契约
原话必须满足三条：
- 主语是「我」（我今天排满了），不是「你」（你总是找我）
- 不解释理由（解释=给人反驳的入口）
- 不附加补偿（不要「下次一定」）

## 反模式（禁止）
- 教他「好好沟通」而不给具体句子
- 预设对方是坏人（证据不足时只描述结构）
- 建议「先冷处理看看」——那是把决定权交回给对方，正是他被消耗的方式
