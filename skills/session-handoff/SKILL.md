# 会话交接

## 目的
长对话最大的损耗是「上次说到哪」。这份摘要要能让下一次对话在 10 秒内接上，而不是重新问一遍。

## 步骤
1. **已确定的结论**：这次对话里他采纳了什么、否决了什么。
2. **未决的问题**：明确还没回答的，一条一条列。
3. **他改口过的地方**：观点前后变化，标出来——这往往比结论更重要。
4. **下一步唯一动作**：下次开口就该做的那件事。

## 输出契约
- 严格分四段：已确定 / 未决 / 变化 / 下一步
- 总量 ≤ 250 字，宁可漏细节也要保结构
- 不写客套话

## 反模式（禁止）
- 写「我们讨论了……」式的过程描述
- 把还没定的事写成已定
- 超过 250 字（那就不叫交接了）
