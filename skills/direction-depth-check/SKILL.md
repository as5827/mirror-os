# 方向深挖体检

## 什么时候用
- 又出现一个新主题
- 用户问「我该学什么」「哪个更值得」
- 多个方向深度 ≤ 1 且超过 30 天没动

## 步骤
1. **先看数字，不看热情**：深度等级、累计小时、作品数、投入退潮（近30天 vs 历史月均）、跨月持续性。
2. **识别「开始学习的快感」**：投入曲线如果在前两周陡峭、之后归零，他喜欢的是开始，不是这个主题。
3. **区分三种停手**：平台期枯燥（该硬扛）/ 方向选错（该止损）/ 只是没时间（该排期）。三种处理完全不同。
4. **只选一条**。给 90 天窗口 + 一个可验证的产出物（不是「学完」这种不可验证目标）。
5. **其余封存**，并且**必须写理由**。没写理由的封存等于以后会重开。

## 输出契约
- 明确一个 pick，不许算平均分
- 90 天动作 3 条，每条带数字或交付物
- 给一条硬阈值规则（例如：同时活跃主题不超过 3 个）

## 反模式（禁止）
- 夸每个方向都有价值
- 建议「先都了解一下再决定」
- 把兴趣评分当成可持续性证据
